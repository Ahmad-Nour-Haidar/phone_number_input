# phone_number_input example

A form with an `InternationalPhoneNumberInput` that shows the reported
`PhoneNumber` live: its country, digits, E.164 form, international format and
type.

Try:

- typing Arabic digits, such as `٠٥٩٩١٢٣٤٥٦`;
- pasting an international number, such as `+966 50 123 4567`;
- switching the app to Arabic with the button in the app bar;
- searching the country list in Arabic.

Run it with:

```sh
flutter run
```
